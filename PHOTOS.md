# Photos à ajouter

Enregistrez vos photos dans le dossier `media/` **avec exactement ces noms**.
Chaque photo apparaît automatiquement sur le site — aucune modification de code
n'est nécessaire. Tant qu'un fichier est absent, son emplacement affiche un
cadre doré indiquant la photo attendue.

## Conseils

- **Format `.jpg`** (pas `.png`) pour les photos — les fichiers sont bien plus légers.
- **Moins de 400 Ko par photo.** Compressez sur [squoosh.app](https://squoosh.app) si besoin.
- Les images en portrait sont **découpées en arche**. Placez le sujet au centre,
  et laissez de l'espace en haut : les coins supérieurs sont rognés.
- Pour `hero.jpg`, choisissez une photo large : la devanture, la vitrine pleine,
  ou le comptoir. Le haut de l'image est arrondi.

## Comment télécharger vos photos Instagram

1. Ouvrez [instagram.com/breadhousemorocco](https://www.instagram.com/breadhousemorocco/)
   sur ordinateur, connecté à votre compte.
2. Ouvrez la publication, cliquez sur **⋯** puis **Télécharger**.
   (Si l'option n'apparaît pas, faites une capture d'écran en haute résolution.)
3. Renommez le fichier selon le tableau ci-dessus et placez-le dans `media/`.

Ce sont vos propres photos : vous avez le droit de les réutiliser. Ne prenez pas
de photos provenant d'autres comptes.
